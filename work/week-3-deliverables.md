## 2. Decide Once: Build Your Identity Kit

### Typography
* **Heading Font:** `Inter` (Weight: 700 Bold) — Chosen for strong, functional structure without decorative distraction.
* **Body Font:** `Inter` (Weight: 400 Regular / 500 Medium) — Chosen for clean legibility across code blocks and dense technical text.

### Color Palette (Hex Codes)
* **Background (Near-White):** `#F9FAFB` *(Calm, clean whitespace)*
* **Text / Main (Near-Black):** `#111827` *(High contrast for effortless reading)*
* **Muted / Borders:** `#6B7280` *(Neutral secondary contrast for subtle boundaries)*
* **Accent Color:** `#2563EB` *(Single muted blue used strictly for active links, buttons, and focus states)*

### Logo & Favicon Mark
* **Favicon:** A minimalist 32x32 SVG icon featuring crisp initial badge `[AS]` in `#FFFFFF` set over a `#2563EB` accent block.
